# TaskFlow — Task Scheduling Using Lattices and Hasse Diagrams

Micro project website for Discrete Mathematics.

## Features
- Responsive modern landing page
- Explanation of partial orders, lattices and Hasse diagrams
- Interactive prerequisite-based task scheduler
- Progress bar and ready-to-start task detection
- SVG Hasse diagram
- Topological ordering demonstration
- Project details for Sandip University

## Run
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/root`.
5. Save and open the generated Pages URL.

## Viva points
1. A partial order is a relation that is reflexive, antisymmetric and transitive.
2. A Hasse diagram represents a finite partially ordered set by showing cover relations.
3. A task dependency can be represented as a partial order.
4. A valid task schedule is a topological ordering of the dependency graph.
5. Lattice concepts can model sets of completed tasks using set inclusion.
