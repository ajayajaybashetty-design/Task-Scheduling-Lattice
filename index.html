CORE IDEA

How mathematics helps scheduling

Task dependencies create a partially ordered set. A Hasse diagram shows the important direct relations, making the dependency structure easy to understand.

≤

Partial Order

If task X must be completed before task Y, we write X ≤ Y. This relation captures prerequisites.

◇

Hasse Diagram

A visual representation of a partial order where redundant transitive edges are removed.

⊔

Lattice View

Sets of completed tasks can be ordered by inclusion, giving a useful lattice-based model of project states.
